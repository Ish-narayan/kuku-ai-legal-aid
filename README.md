# Nyaya AI

A prototype AI legal aid assistant for ordinary people in India, focused on rental deposits, unpaid salary, and online refunds.

## Run

```bash
npm install
npm run dev
```

## Assumption
This prototype is informational, not legal advice. It uses a deterministic rules engine to prevent unsupported legal claims. A production version should replace or augment the engine with an LLM constrained by reviewed Indian law sources and a lawyer escalation flow.
